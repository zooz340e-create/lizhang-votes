# 做一支短影音

產線在 `video/`，讀 `video/README.md` 拿 config 欄位定義。
**不要另外寫剪接程式，也不要改渲染器去遷就素材** —— 只寫 config.json。

## 流程

1. **看素材**。`ls video/projects/<專案>/media/`，用
   `video/node_modules/ffmpeg-static/ffmpeg -i <檔案>` 讀每個檔的長度與尺寸。
   決定哪一段好看：直接抽幾張影格出來看，不要用猜的。

2. **先寫腳本再排鏡頭**。30 秒約 150–170 個中文字。
   結構固定：**0–3 秒爆點數字 → 對比 → 這跟你有關 → 工具能做什麼 → CTA**。
   前 3 秒沒有鉤子這支就廢了。

3. **數字一律從 `public/data/` 撈**，寫個一次性 node script 算，不要手打，也不要
   從記憶裡引用。撈完把數字回報給使用者確認再放進影片。

4. **寫 config.json**。鏡頭總長必須等於 `duration`。
   字幕一行約 13 個中文字，超過用 `\n` 自己斷句，別讓它孤字換行。

5. **算**。先 `--preview 8` 確認開頭，好了再算整支。

6. **看過再交**。抽 3–4 張關鍵影格（爆點數字、CTA、最亮的那顆鏡頭）用 Read 看過。
   常見問題：字撞到畫面重點、淺色背景上字看不清、數字跳完太早消失。

7. 用 SendUserFile 把 mp4 和封面交給使用者。

## 內容紀律（跟專案 README 一致）

- **不出現真實里長姓名**。只用地名 + 數字。
- 不用「崩／弱／虛／鬆」這類貶低現任的字眼。
- 估算值要說是估算；官方數字才講得死。

## 做不到的事，直說

- **沒有語音合成** —— 旁白一定要使用者自己錄。
- **不找配樂** —— 版權要使用者自己處理。
- **看不到 Instagram / TikTok 連結** —— 網路代理擋掉了，請使用者用文字描述參考影片。
