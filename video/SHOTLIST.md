# 第一支：〈全台最好選的里，36 票就當里長〉拍攝清單

30 秒 ・ 1080×1920 ・ 直式 ・ 實拍 B-roll + 旁白

你只要做三件事：**錄旁白**、**拍 9 顆空景**、**錄一段螢幕操作**。
丟進 `video/projects/01-calculator/media/`，跑一行指令就出片。

## 一、旁白逐字稿（先錄這個，最重要）

用手機語音備忘錄，安靜房間，離嘴 15–20 公分，**一次錄完不要停**。
念錯就停兩秒重念那一句，剪接時我抓最好的一次。目標 **30 秒內念完**。

| 時間 | 台詞 |
|---|---|
| 0.0–2.5 | 全台最好選的里，三十六票就能當里長。 |
| 2.7–5.8 | 花蓮鳳林森榮里，整個里只有八十個人有投票權。 |
| 6.1–9.4 | 但高雄左營菜公里，要七千九百三十四票才選得上。 |
| 9.7–12.8 | 同樣一個里長，差了兩百二十倍。 |
| 13.1–16.8 | 所以重點不是要幾票，是你家的里要幾票。 |
| 17.1–21.3 | 我做了一個免費工具，選你家的里，三秒算給你看。 |
| 21.6–25.8 | 保證金門檻、近三屆實際當選票，還有參選機會指數。 |
| 26.1–28.5 | 全台七千九百八十二個里都查得到，資料來自中選會。 |
| 28.6–30.0 | 連結在個人簡介。 |

**語氣**：像跟朋友講一件你剛發現的事，不是播新聞。第一句要最有精神。
存成 `media/vo.m4a`（m4a / mp3 / wav 都可以）。

> 我這邊沒有語音合成能力，旁白一定要你自己錄。錄完我會自動做語音正規化
> （音量拉平）＋配樂自動閃避，你不用管混音。

## 二、9 顆畫面（手機直式拍，每顆比表定多拍 2 秒）

| # | 秒數 | 拍什麼 | 提示 |
|---|---|---|---|
| 1 | 2.6 | 鄉間小路／里辦公處門口招牌 | **開頭決定生死**。找有「里」字的門牌或招牌，慢慢往前推 |
| 2 | 3.4 | 安靜小聚落、老房子、幾乎沒人的街 | 要「空、少、慢」，對比用 |
| 3 | 3.6 | 都市大社區、一整排高樓 | 要「滿、多、密」，跟第 2 顆強烈對比 |
| 4 | 3.4 | 人潮或車流 | 稍微快一點的節奏 |
| 5 | 4.0 | 手指滑手機的特寫 | 手部特寫，畫面乾淨 |
| 6 | 4.5 | **螢幕錄影**：選縣市 → 選區 → 選里 | 手機開 lizhang-votes.vercel.app 直接錄螢幕 |
| 7 | 4.5 | **螢幕錄影**：三張卡往下滑 | 滑慢一點，讓人看得到數字 |
| 8 | 2.6 | 空拍拉遠／城市全景 | 收尾的呼吸感 |
| 9 | 1.4 | 不用拍 | 結尾卡是圖文，已經做好了 |

**通則**
- 手機**直式**、鎖定曝光、盡量用 4K 或 1080p 60fps（我會轉成 30fps）
- 每顆都是**單一動作**：只推進、或只平移，不要又推又轉
- 別在畫面下半部放重點 —— 字幕會蓋在那裡
- 陰天或室內窗邊最好看，正中午硬光最難看

**檔名**：`shot1.mp4` ～ `shot8.mp4`，放進 `media/`。照片也可以（`.jpg`），
我會自動加緩慢推鏡（Ken Burns）。

> 最難選的要 7,934 票。差了 220 倍。

> 選你家的里，三秒就知道要幾票才能退保證金、近三屆實際當選票是多少。
>
> 資料來自中選會與內政部戶政司。連結在個人簡介。

> #里長 #地方選舉 #2026選舉 #村里長 #選舉資料
